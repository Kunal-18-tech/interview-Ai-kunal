1. Executive Summary & Overview

InterviewIQ AI Pro is a state-of-the-art, competition-level autonomous mock interview platform. It simulates real-world hiring environments by pairing candidates with an animated AI interviewer avatar, live speech recognition, real-time audio/visual telemetry, an integrated code sandbox, an architectural whiteboard, and a multi-dimensional semantic scoring system.

The platform operates with zero backend dependencies using modern client-side Web APIs, local persistence databases, and fallback NLP evaluation heuristics. It also supports direct Google Gemini API integration for live LLM response analysis.

2. Complete Feature & Module Breakdown

🔐 1. Authentication, Multi-User Sessions & Role-Based Access Control (RBAC)

File: login.html, js/storage.js

  • Secure Local DB: Multi-user registration and encrypted password storage (Base64 hash abstraction) in localStorage under interviewiq_users_db.
  • Session Isolation: Active user authentication managed through sessionStorage with route guards on index.html and admin.html.
  • One-Click Guest Access: Allows rapid trial mode without registration.
  • Admin Role Separation: Dedicated administrator account with exclusive access to the system telemetry and management dashboard.

🛡️ 2. Admin Command Center & Real-Time Traffic Analytics

File: admin.html

  • Live Platform KPI Cards: Real-time counts for Total Users, Successful Logins, New Registrations, Guest Sessions, Failed Attempts, Total Interviews Taken, and Platform Average Score.
  • 7-Day Activity Histogram: Dynamic visual bar chart summarizing daily user engagement.
  • Real-Time Activity Log Feed: Instant chronological stream of all security and session events (Logins, Registrations, Guest Access, Failed logins).
  • User Directory & Management: Comprehensive table of all registered users with interview metrics and one-click user deletion.
  • Log Export & Clear Tools: Administrative data sanitation and management utilities.

🎙️ 3. Animated AI Interviewer Avatar & Speech Synthesis

File: js/avatar.js, js/speech.js

  • Interactive SVG Avatar: Vector-based avatar with real-time lip synchronization, eye blinking, listening pulse animations, and expressive state transitions (Idle, Speaking, Thinking, Listening).
  • Web Speech Synthesis (TTS): Natural voice narration of dynamic interview questions with adjustable pitch, rate, and voice profile selection.
  • Web Speech Recognition (STT): Continuous speech-to-text transcription converting spoken answers into text transcripts with real-time word counting and filler-word detection.

📊 4. Real-Time Telemetry & Audio-Visual Bio-feedback

File: js/analytics-realtime.js

  • Webcam Video Stream: Live client-side camera preview with frame stability tracking.
  • Audio Volume VU-Meter: Live Web Audio API frequency analysis monitoring voice clarity and input energy.
  • Speaking Pace (WPM Meter): Real-time Words-Per-Minute monitoring alerting users if they are speaking too fast (>160 WPM) or too slow (<90 WPM).
  • Filler Word Counter: Real-time detection and counting of hesitation words ("um", "uh", "like", "basically", "literally", "you know").

🧠 5. 7-Dimensional Semantic Scoring Engine

File: js/ai-engine.js

The platform evaluates candidate answers across 7 core industry competencies:

Evaluation Dimension Weight Criteria & Signals Detected
Technical Accuracy 25% Architecture terms, algorithms, data structures, complexity (Big O), concurrency.
STAR Framework Structure 15% Situation, Task, Action, Result methodology clarity in behavioral scenarios.
Clarity & Articulation 15% Sentence flow, vocabulary precision, minimal filler words, concise reasoning.
Problem-Solving Methodology 15% Root-cause identification, edge-case consideration, trade-off analysis.
Quantitative Metrics 10% Inclusion of concrete numbers, percentages, latency reduction, scale metrics.
Confidence & Pace 10% Consistent audio energy, optimal speech pace (100–140 WPM).
Domain Specificity 10% Role-specific terminology (Frontend, Backend, System Design, DevOps, HR).

💻 6. Integrated Code Sandbox & Execution Environment

File: js/code-editor.js

  • Multi-Language Code Editor: Syntax-aware editor supporting JavaScript, Python, C++, Java, and SQL.
  • In-Browser JavaScript Execution: Safe iframe-sandboxed runtime executing JavaScript code with output console logging and execution time tracking.
  • Starter Boilerplates: Preloaded algorithmic problem templates (Two Sum, LRU Cache, Binary Tree traversal).

📐 7. Interactive Architecture & Whiteboard Canvas

File: js/whiteboard.js

  • HTML5 Canvas Whiteboard: High-performance vector drawing tool with pen, rectangle, circle, text, eraser, and color palette.
  • System Architecture Pre-sets: Ready-to-use building blocks for Microservices, Load Balancers, Redis Caches, and SQL Databases.
  • Export Capability: One-click PNG canvas export for design artifacts.

📄 8. Resume PDF Parser & Adaptive Question Generator

File: js/pdf-parser.js

  • Client-Side PDF Extraction: Parses uploaded candidate resumes using PDF.js.
  • Keyword & Skill Extraction: Automatically extracts technical stack (e.g. React, Node, AWS, Docker, Kubernetes, SQL) and customizes interview questions around candidate experience.

🏆 9. Official Verified Certificate of Performance

File: js/certificate.js

  • Dynamic Canvas Rendering: Generates a high-resolution, branded certification diploma.
  • Cryptographic Verification Hash: Issues a unique verification ID based on the candidate score, timestamp, and evaluation breakdown.
  • Instant PDF/PNG Download: Candidates can export and share their credential on LinkedIn or portfolios.

5. Deployment & Hosting Guide

InterviewIQ AI Pro is 100% static and can be deployed in under 60 seconds on any global Edge CDN:

  1. Netlify Drop (Recommended): Drag the interviewiq-ai folder into app.netlify.com/drop for an instant HTTPS URL.
  2. Vercel: Run vercel deploy or connect your GitHub repository.
  3. GitHub Pages: Push to a GitHub repository and enable Pages in repository settings.
